# 训练概述

本文介绍训练方法和验证原则，不包含具体超参数、种子划分、算力安排和逐轮实验记录。

## 整体结构

```
游戏状态 ──► 特征（57 项，本机可观测） ──► prior 引导律 ──┐
                                   └──► 小型 MLP 残差 ──┴─► 限幅相加 ──► 指挥器授权 ──► 原版操纵接口
```

- **Prior（基础引导）：** 用跑道几何、下一环位置、能量状态和左右推力计算俯仰、滚转、偏航、油门和刹车。它可以单独飞完进近，也是所有学习结果的比较基线。
- **残差网络：** 小型 MLP，在每个轴的固定幅度内修正 prior。空中和地面使用不同的输出头。
- **指挥器：** 与模型无关的规则层，负责接通窗口、驾驶员优先、数据过期、起落架与复飞、反推和交还。

## 孪生环境

- 用 JAX 实现的飞行孪生。它以实机录制做积分器回放校验，录制回放的位置误差在毫米级以内。
- 双发、维修、火情、结冰、雨、雾和阵风，都按游戏代码中的参数建模。
- 确认过的原生机制直接进入孪生：起落架卡滞与手摇、前锋阵风的 ±12° 滚转冲击，以及接地时的坠机、擦地和 HardLanding 判定。
- 观测延迟和掉包作为独立的压力维度，用来模拟联机客户端的情况。

## 训练流程

1. **教师：** 基于采样的模型预测控制（MPPI 类方法），在孪生中规划出高质量的操纵序列。同时使用两种教师：一种能看到未来扰动，另一种看不到。比较两者，可以区分“控制本身能改进的部分”和“只有预知扰动才能改进的部分”。
2. **模仿与 DAgger：** 学生先模仿教师；再让学生自己飞，由教师对偏离状态重新标注，减少分布漂移。
3. **截断 BPTT 微调：** 在可微孪生中，对接地前后的短时段直接反向传播一个平滑的着陆包线损失，并在独立验证集上早停。当前发布的权重来自这一步。

## 评估与选型原则

- 训练、验证和留出评估使用互不重叠的场景种子；候选冻结后，再用一批全新种子复核。
- 比较时，同一种子上的候选与 prior 配对；用种子自助法计算置信区间，并注意多候选择优带来的乐观偏差。
- 先看安全：在支持的延迟范围内（0–300 ms），任何候选只要比 prior 多出一次坠机或冲出跑道，就不采用。其次才看成功率、接地下沉率和擦地次数。
- 失败按原因分类，例如漏环、翼尖擦地、接地偏重、起落架未锁定交还、超时，并把游戏原生判定下的坠机单独计数。

## 主要结论

- 起落架未锁定导致的“坠机”原来是孪生缺陷；补上原生的手摇模型后，这部分失败基本消失。
- 学习带来的提升有限：BPTT 微调后的模型在支持延迟范围内略好于 prior，翼尖擦地明显减少；加入原生阵风冲击后两者大致持平。
- 剩余的失败主要来自观测延迟造成的信息差，继续扩大训练收益很小。后续方向见 [研究计划](roadmap.md)。
- 按游戏原生判定，所有评估中的坠机数都是 0。

## 可复现性

`tools/mayday_landing` 包含环境、教师、训练和评估的代码，`tools/tests` 覆盖关键行为。发布权重只保留推理所需的字段，训练元数据不随仓库发布。
